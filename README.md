# Electricidad Lakuntza Web

Web profesional para Electricidad Lakuntza / Elektrizitatea.

## Stack

- Next.js 14
- React
- Tailwind CSS
- Lucide Icons
- Deploy recomendado: Vercel

## Desarrollo local

```bash
npm install
npm run dev
```

## Despliegue en Vercel

1. Entrar en Vercel.
2. Importar el repositorio `Gorkaa96/electricidad-lakuntza-web`.
3. Framework: Next.js.
4. Build command: `npm run build`.
5. Output: automático.
6. Deploy.
